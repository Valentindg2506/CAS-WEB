# CAS Real State – Página Web.

Proyecto web desarrollado para **CAS Real State**, una agencia inmobiliaria enfocada en brindar acompañamiento completo al cliente durante los procesos de compra, venta o alquiler de propiedades.

Este sitio está diseñado para transmitir **profesionalismo, confianza y claridad**, con secciones que presentan los servicios, el paso a paso de cada proceso y reseñas reales de clientes satisfechos.

---

## 🌐 URL del proyecto

https://www.casrs.es

---

## 📌 Características principales

- **Página hero con imagen panorámica de Valencia**
- **Sección de servicios** 
- **Seccion de reseñas**
- **Agenda de citas**
- **Diseño moderno, responsive y orientado a conversión**
- **Animaciones suaves**

---

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
